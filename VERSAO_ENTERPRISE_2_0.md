# Enterprise 2.0

Esta versão substitui a interface inicial de MVP por uma experiência de preparação profissional.

Principais mudanças:
- Nova identidade visual e UX responsiva
- Sidebar recolhível
- Dashboard orientado à meta de preparação
- Biblioteca visual de treinamentos
- Cadastro em modal
- Estúdio bilíngue aprimorado
- Plano de preparação de 12 semanas
- Laboratório de pronúncia
- Simulador em formato de conversa
- Login redesenhado
- Correção definitiva da incompatibilidade bcrypt/passlib
